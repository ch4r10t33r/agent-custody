# site

The website at agent-custody.dev, generated by VitePress from the repository's own markdown: the root README (by region), the receipts guides, the state and Python READMEs. Nothing here is a second copy of the docs. The site's own pages are the landing page, the guide index pages, and the receipt specification at `/receipt/v0.2`, which is the URL every receipt's `predicateType` carries.

```bash
bun run site:dev      # from the repository root; live reload
bun run site:build    # site/.vitepress/dist
```

Relative links in the docs are rewritten at build time: links to markdown pages become site links, links to source files become links into the repository on GitHub.
